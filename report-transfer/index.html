원문 붙여넣기 → 편집 → 기안문·학사정보 서식 복사

0개 문단/표 선택

원본 붙여넣기

오른쪽에서 본문·셀 내용을 직접 수정합니다. 표는 Ctrl+드래그로 셀 사각형 선택, 열 경계 드래그로 너비 조절합니다. 이미지는 Ctrl+V로 삽입하며 모서리를 드래그하면 비율을 유지하고 Ctrl을 누르면 자유롭게 크기를 바꿉니다. Ctrl+클릭은 떨어진 문단 복수 선택, Shift+클릭은 연속 선택입니다. Tab/Shift+Tab으로 단계도 바꿀 수 있습니다.

금액·%는 오른쪽 정렬 · 나머지는 가운데 정렬 · 선택한 서체 · 본문 가로 구분선 점선. 정해진 폭을 넘는 내용은 자간을 줄이고, 그래도 길면 줄바꿈합니다.

설치 없이 브라우저에서 변환합니다. 문서는 서버로 전송되지 않습니다. 초안은 저장 버튼으로 이 브라우저에 저장하고, 백업 파일로 다른 PC에 옮길 수 있습니다. 선택한 서체가 없는 기기에서는 대체 글꼴로 표시됩니다. 학사정보용 기본 본문 배경은 투명하여 게시판 배경을 그대로 따릅니다.

표를 붙여넣어 주세요. 기안문은 HTML 소스 모드가 아닌 일반 본문에서 붙여넣습니다.아세아항공직업전문학교 · 웹 버전

위계 설계

기호는 {n}(숫자), {ko}(가나다) 또는 직접 입력합니다. 앞 공백은 단계마다 실제 스페이스 2칸(0·2·4·6·8·10칸)이며 기호 뒤는 한 칸입니다.

예시로 설계

예시를 입력하고 한 줄을 드래그한 뒤 해당 단계의 ‘선택 줄 읽기’를 누르세요. 앞 공백과 기호를 읽습니다.

휴대폰에서는 브라우저의 ‘홈 화면에 추가’를 이용합니다. Safari는 공유 메뉴에서 선택합니다.
이 버튼이 임의로 PC에 프로그램을 설치하지는 않습니다. 브라우저의 설치 확인을 완료해 주세요. 인터넷 연결이 필요합니다.
