# 아세아 이음 (ASEA IEUM) 브랜드 및 출시 기준

## 서비스 정체성
- 공식 국문명: **아세아 이음**
- 영문 브랜드: **ASEA IEUM**
- 의미: 교직원을 잇는 대화, 부서와 업무를 잇는 기록, 학교 공동체의 소통 문화
- 화면 표어: **함께 이어가는 소통**
- 서비스 명칭을 '업무 시스템', '통합 공지' 등 투박한 표현에서 '아세아 이음'으로 통일
- 제안 출시 명칭: **아세아 이음 1.0** (정식 배포 기능·보안 검증 완료 시 부여)

## 배포 버전 구분
- 현 개발 앱: `0.1.0` 시험용. '1.0 출시 완료'로 표현 금지
- 정식 출시 시: Android `versionName=1.0.0` 및 증가한 `versionCode`, iOS CFBundleShortVersionString 1.0.0, Windows 설치 파일 1.0.0
- GitHub 저장소 `asea-college/asea` 및 Supabase `asea-workspace` 식별자 유지
- Android applicationId, iOS bundle id, Windows Inno Setup AppId, 사용자 데이터, 설치 설정, 서명 정보는 호환성 검토 전 변경하지 않음

## 기능 체계
- 이음 대화: 전체/부서/개인 메시지, 업무 인수인계, 조용히 나가기
- 이음 공지: 중요 공지, 확인/미확인 집계, PC 팝업, 모바일 푸시
- 이음 모임: 익명/실명 투표, 일정 조율, 팀 추첨, 랜덤 점심, 퀴즈
- 이음 방송국: 방송 편성, DJ, 합법적인 음원·오디오 콘텐츠 재생 (권리 확인·사용자 재생 동의·장치 지원 검증 필수)
- 이음 관리자: 가입 승인, 공식 부서명, 부서 이동, 권한 관리, 기록 보존

## 보존·비용·개인정보
- 일반 대화 3년, 공식 공지·업무기록 5년 기본안, 법적 보존 의무 우선.
- 기존 Supabase Free 유지 및 신규 비용 전 승인.
- 사용자 비밀번호·서비스 비밀키는 앱 소스에 하드코딩하지 않음.
