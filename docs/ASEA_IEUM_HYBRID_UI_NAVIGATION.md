# 아세아 이음 — 통합 디자인 및 모바일 슬라이드 내비게이션 결정

- 기준 UX: 프리미엄 업무형(A)의 정보 구조 + 커뮤니티형(B)의 친근한 카드 + 미니멀형(C)의 타이포그래피.
- 공식 앱명: 아세아 이음 / ASEA IEUM.
- 서체: Pretendard, 일반 본문 400/500·강조 600·제목 700.
- 공통 색상: 네이비 #17365D, 액션 블루 #245A9C, 소프트 블루 #EDF4FC, 포인트 민트 #E9F5EF, 글자 #21364E.
- 모바일: 상단 햄버거 메뉴 버튼 또는 화면 왼쪽 가장자리에서 오른쪽 스와이프 → 300dp 메뉴 열림; 열린 메뉴 왼쪽 스와이프·닫기 버튼 → 메뉴 닫힘.
- drawer 닫힌 상태: 채팅 리스트/콘텐츠 전체 폭 사용; 13개 메뉴 레이블을 업무/소통/계정 그룹으로 정리.
- 접근성: 화면에 열린 메뉴의 닫기 버튼 표시, 메뉴 버튼 tooltip, 스크롤 가능 메뉴, 작은 화면 대응.
- 사용자가 주로 요청한 슬라이드형 메뉴는 `apps/mobile/lib/main.dart`의 Flutter Scaffold Drawer로 구현. Android/iOS 동일 코드 사용.
- 웹: `apps/portal/ieum-theme.css` 공유 토큰을 메시지함, 소통센터, 마니또 페이지에 적용.
- Windows: 별도 WinForms 앱으로 공통 디자인 시스템 전체 이식은 아직 미완료. Android/iOS Flutter와 동일한 UI라고 주장하지 않는다.
- 이 디자인은 소스 구현 단계. 실제 기기 제스처 검증, 13개 메뉴의 개별 기능 완성, 네이티브 iOS 설치 테스트, PC 통합 기능 검증은 남아 있다.
- 임시 메뉴 링크가 기존 공통 화면으로 연결되는 항목은 각 메뉴의 독립 기능 완료 전에 완성으로 표기하지 않는다.
