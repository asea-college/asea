# ASEA 통합 포털 — 디자인·대화 보존·운영 확정 기준

확정일: 2026-10-31
관련 서비스: Windows PC 앱, Android, iOS, 관리자 웹, 공통 Supabase `asea-workspace`.
비용 정책: **현재 Free 유지**, 유료 전환·추가 과금 전에 사용자 승인 획득.

## 1. 화면과 기능
- **디자인 시안 3번**을 기준으로 PC/모바일 반응형 UI 구현: 파란 좌측 메뉴, 대화방 목록 + 시간순 메시지 상세, 모바일 하단 탭.
- 모든 교직원 직접 가입: 아이디 + 비밀번호, 이메일 선택. 관리자가 가입 승인 후 이용.
- 시스템 URL 및 Publishable Key는 일반 로그인 화면에서 제거; 공개용 설정만 앱 설정에 포함하고 관리자는 서버 설정 메뉴에서 관리.
- 최고 관리자: 전체 공지 작성·발송, 발송 권한 관리, 확인·미확인자 집계.
- 승인된 모든 교직원: 별도 **일반 메시지**의 전체/부서/개인 대상 발송 가능. 공식 공지·중요 공지 발송 권한과 별개.
- 부서장: 부서원 선택 및 부서별 메시지 발송. 개인 채팅도 지원.
- 대화 기록은 방마다 날짜 구분선과 시간순 버블로 누적. PC/모바일에서 동일한 서버 기록을 조회.
- 중요 공지: 모바일 푸시 + PC 팝업 + 확인 버튼 + 미확인자 집계.
- 파일 첨부, 검색, 대화방 분류, 미읽음 수, 오래된 대화 페이지네이션 지원.

## 2. 기록 등급·기본 보존
| 기록 유형 | 기본 보존 | 시작 시점 |
| --- | --- | --- |
| 일반 개인·부서·전체 메시지 | 3년 | 서버 수신·생성 시각 |
| 공식 공지·중요 확인 공지 | 5년 | 공지 게시 시각 |
| 업무 증빙성 기록 및 필수 확인 기록 | 5년 | 해당 기록 확정 시각 |

- 별도의 법정 의무, 분쟁 보전, 감사·소송·계약상 보존 필요가 확인되면 해당 기준을 우선하며 법적 검토 전 무조건 삭제하지 않는다.
- 원본 메시지/첨부파일과 수신·확인 기록을 분리해 중복 저장 방지.
- 서버에는 UTC 시각 저장, 표시 시 Asia/Seoul 시간대로 변환.
- 보존 기한 도달 시 **삭제 후보만 추출**; 실제 삭제·복원 불가능한 익명화·Storage 정리는 관리자 승인과 백업 후 시행.
- `legal_hold`가 활성화된 기록은 자동 삭제 대상에서 제외한다.
- 퇴직·탈퇴와 업무기록 보존을 구분하고 개인 정보 접근 권한을 최소화한다.
- 파일 첨부, 로그, 백업본 등 동일 개인정보의 파생 데이터까지 보존·삭제 범위를 일치시킨다.

## 3. 운영 예산·사용량
- 기존 Supabase `asea-workspace` Free 유지.
- 60명 동시 사용량을 가정한 메시지 양, Storage 첨부 크기, DB 사용량·전송량을 주기적으로 관측.
- DB는 메시지 본문 1개 + 수신/읽음 별도 행 저장. 3·5년 보존 기준으로 인덱스·페이지네이션 설계.
- 백업 정책, 유료 플랜 제안, 추가 비용 확인은 운영 배포 전 별도 보고.
- 무료 한도에 접근해도 승인 없이 자동으로 Pro로 변경하지 않는다.

## 4. 구현·검증 게이트
1. 공통 메시지 데이터 모델, 대화방 구성원·부서/전체/개인 발송 권한, RLS, 가입 승인 구현.
2. PC/Android/iOS 동일 대화 조회·발송·확인·푸시 실기기 검증.
3. 보존 기한 메타데이터, 삭제 후보 검토·법적 보존 예외·복구 절차 구현.
4. CI 빌드, 인증/권한/서로 다른 계정 격리 테스트, PR 병합 및 운영 배포 후 검증.
5. 설치 파일·APK·iOS 배포 경로, 해당 버전 및 제약 기록.

## 5. 이번 변경 상태
이 문서는 확정된 요구사항과 기본 보존 정책이다. 별도 마이그레이션은 보존 분류를 정의하는 독립 테이블만 추가하고 **자동 삭제 작업을 설치하지 않는다.** 전체 PC/모바일 기능 완성을 의미하지 않는다.
