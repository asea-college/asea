# ASEA 규정 근거 도우미 — 프론트엔드 1차

기존 `asea-college/asea` 저장소의 `regulation/`에 배치하는 빌드 없는 정적 웹앱입니다. 기존 루트 화면과 course 서비스는 변경하지 않습니다.

## 현재 동작
- PDF.js 4.10.38로 텍스트 PDF 추출(외부 CDN 로드 필요), 원본 PDF와 텍스트를 IndexedDB에 보관
- 문서명, 시행일, 발행기관, 적용 범위 등록 및 원문 검수 체크
- 제N조·제N조의N 기준 조문 분리, 조문 검색과 원문 복사
- 업무 문장에서 키워드 후보 검색, 사용자 선택 근거 목록 구성 및 복사
- JSON 텍스트 백업/가져오기(원본 PDF 제외), 삭제
- 미래 시행 문서는 검색에서 제외. 개정본 자동 대체나 우열 판단 없음

AI 추론, OCR, 공동 DB, 인증은 구현 전입니다. 키워드 일치 결과를 법적 적용 판단으로 표시하지 않습니다. 실제 학교 규정이나 가상 조문은 포함하지 않습니다. 내부 문서가 공개 저장소로 전송되지 않습니다.

## 실행
저장소 루트에서 `python -m http.server 8080` 실행 후 `/regulation/` 방문합니다. GitHub Pages가 루트 main을 배포하도록 설정되어 있다면 같은 경로로 제공됩니다.

## 후속 DB 연결 계약
Supabase에 documents, document_versions, provisions, attachments, provision_links, search_chunks와 비공개 Storage를 구성합니다. 교직원 로그인 및 RLS 정책을 먼저 적용한 뒤 브라우저 저장 구현을 서버 어댑터로 교체합니다. 공개 웹앱에는 service_role 키나 AI 비밀키를 넣지 않습니다. AI는 조문 ID를 출력하고 서버가 권한·유효기간·원문을 재검증하도록 합니다. PDF 자동 추출 결과는 검수 전 검색에서 제외합니다.

## 제한
PDF 표·다단 편집·목차·부칙은 자동 분리 오류가 있을 수 있어 원본 확인이 필수입니다. 전문 한국어 형태소 분석 및 의미 검색이 없으므로 표현이 다른 검색어는 누락될 수 있습니다. 검수된 텍스트만 검색하며 기존 개정본은 직접 삭제·정리해야 합니다. 브라우저 저장소는 사용자별 권한 관리나 영구 공동 보관을 제공하지 않습니다.
