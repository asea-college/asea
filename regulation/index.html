GETTING STARTED

PDF부터 준비하시면 됩니다.

현재 이용 순서

  1. 문서 관리에서 PDF를 선택합니다.
  2. 문서명·시행일·발행기관·적용 범위를 입력합니다.
  3. 추출된 원문과 조문 분리 결과를 확인합니다. 별표는 연결된 조문과 함께 확인합니다.
  4. 검수 확인 후 등록하면 규정 검색과 기안 근거 찾기에서 사용할 수 있습니다.
  5. 필요한 원문 또는 기안 문구를 복사해 그룹웨어에 붙여넣습니다.

현재 기능 범위

텍스트 PDF 추출, 조문 분리, 브라우저 내 저장, 키워드 검색, 조문 선택, 복사가 작동합니다. PDF 처리를 위한 라이브러리를 외부 CDN에서 불러오지만 선택한 PDF 내용은 서버로 업로드하지 않습니다.

교직원 공동 사용을 위한 Supabase DB·로그인·권한, 개정 이력 비교, OCR, AI 의미 검색과 추론은 후속 연결 대상입니다. 현재 시행일이 미래인 문서는 기본 검색에서 제외됩니다. 개정본을 등록하면 기존 자료를 직접 정리해야 합니다.

다음 연결 단계

Supabase 프로젝트를 확정한 뒤 비공개 파일 저장소와 조문 DB, 사용자 권한을 연결합니다. 이후 PDF 등록 자료를 여러 PC에서 공유하고 AI 근거 추천 기능을 추가합니다.
